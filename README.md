# SIEMMap

Mapa pokrycia źródeł logów SIEM: inwentarz serwerów i urządzeń, katalog „typ urządzenia → rola → pakiet”
(co logować, czego nie, konfiguracje dla Splunka, Wazuha i Elastica) oraz śledzenie, co faktycznie jest zbierane.

## Uruchomienie

Otwórz `index.html` w przeglądarce. Aplikacja działa lokalnie, bez serwera; dane są szyfrowane i zapisywane w przeglądarce.
